# IT Asset, Phone Directory & Dashboard System

ระบบจัดการอุปกรณ์ IT และสมุดโทรศัพท์ภายใน สำหรับทีม IT Support โรงพยาบาล (ใช้งานคนเดียว, รองรับหลายสาขา) สร้างด้วย HTML + Tailwind CSS + Vanilla JS (Frontend บน GitHub Pages) และ Google Apps Script + Google Sheets (Backend/Database)

## โครงสร้างไฟล์ (ต้องอยู่ที่เดียวกันทั้งหมด)

```
index.html   → หน้าเว็บหลัก (Dashboard / ค้นหาเบอร์ / จัดการอุปกรณ์)
app.js       → โค้ด Logic ทั้งหมดฝั่ง Frontend
Code.gs      → โค้ด Backend สำหรับวางใน Google Apps Script
1.jpg        → ไอคอน/โลโก้เว็บ (ถ้ามี ให้ใช้ชื่อไฟล์นี้เท่านั้น — ยังไม่ได้แนบมาด้วย ต้องอัปโหลดเพิ่มเอง)
README.md    → เอกสารฉบับนี้
```

> `index.html` อ้างอิง `1.jpg` เป็น favicon ไว้ล่วงหน้าแล้ว หากยังไม่มีไฟล์ไอคอน เบราว์เซอร์จะแสดงไอคอนเริ่มต้นแทนเฉยๆ ไม่กระทบการทำงานอื่น

## สาขาที่รองรับ

`อโศก`, `ปิ่นเกล้า`, `อุดร` (แก้ไข/เพิ่มสาขาได้ที่ตัวแปร `BRANCHES` ทั้งใน `app.js` และ `Code.gs` ต้องแก้ให้ตรงกันทั้งสองไฟล์)

## ขั้นตอนติดตั้ง

### 1. สร้าง Google Sheet + วาง Backend

1. สร้าง Google Sheet ใหม่ 1 ไฟล์ (นี่จะเป็นฐานข้อมูลทั้งหมด)
2. เปิด **Extensions > Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาไฟล์ `Code.gs` ลงไป
4. เลือกฟังก์ชัน `setupSheets` จาก dropdown ด้านบน (ข้าง Debug) แล้วกด **Run** ครั้งเดียว
   - ระบบจะสร้างชีตทั้งหมด (IPPhone, EDC, Pinpad, PrinterServer, PC, Log) พร้อมหัวตารางให้อัตโนมัติ
   - ครั้งแรกที่ Run จะมีป๊อปอัพขอสิทธิ์ (Authorize) ให้กด Review permissions > อนุญาต
5. กด **Deploy > New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL**

### 2. เชื่อม Frontend เข้ากับ Backend

เปิดไฟล์ `app.js` แล้วแก้บรรทัดนี้ให้เป็น URL ที่คัดลอกมา:

```js
const API_URL = 'https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXXXXX/exec';
```

### 3. Deploy ขึ้น GitHub Pages

1. อัปโหลด `index.html`, `app.js`, `1.jpg` (ถ้ามี) ไว้ที่ root ของ repo เดียวกัน
2. เปิด Settings > Pages > เลือก branch ที่ต้องการ > Save
3. เข้าใช้งานผ่านลิงก์ GitHub Pages ที่ได้

> ทุกครั้งที่แก้ `Code.gs` ต้อง Deploy ใหม่ (หรือ Manage deployments > Edit > New version) ไม่เช่นนั้นระบบจะยังใช้โค้ดเวอร์ชันเก่าอยู่

## โครงสร้าง Google Sheets (สร้างอัตโนมัติโดย `setupSheets()`)

ทุกชีตอุปกรณ์มีคอลัมน์ร่วมกันชุดแรกเหมือนกัน: `ID | สาขา | อาคาร | ชั้น | แผนก | ตำแหน่งย่อย` แล้วตามด้วยคอลัมน์เฉพาะของแต่ละประเภท ปิดท้ายด้วย `สำรอง | หมายเหตุ | อัปเดตล่าสุด`

| ชีต | คอลัมน์เฉพาะ |
|---|---|
| **IPPhone** | เบอร์ภายใน, IP Address, สายตรง |
| **EDC** | ธนาคาร, TID, MID, IP/SIM, Pinpad ที่เชื่อมต่อ (เลือกจาก Serial Number ของ Pinpad ที่มีอยู่) |
| **Pinpad** | Serial Number, PC การเงินที่เชื่อมต่อ |
| **PrinterServer** | Hostname, IP Address, MAC Address, ชื่อ Share Printer, รุ่นตลับหมึก, เลข AnyDesk (เครื่อง Printer/Print Server รวมเป็นประเภทเดียวกัน) |
| **PC** | Hostname, IP Address, MAC Address, เลข AnyDesk, สเปกเครื่อง |
| **Log** | เวลา, การกระทำ, ประเภท, ID รายการ, รายละเอียด (บันทึกอัตโนมัติทุกครั้งที่ เพิ่ม/แก้ไข/ลบ) |

- `ID` เป็นรหัสสุ่ม 8 หลัก สร้างอัตโนมัติตอนเพิ่มรายการใหม่ (ห้ามแก้มือใน Sheet เพราะระบบใช้อ้างอิงตอนแก้ไข/ลบ)
- `สำรอง` เป็นค่า TRUE/FALSE ใช้แทนสถานะ "อุปกรณ์สำรองพร้อมใช้งาน" (ยังไม่ทำระบบสถานะเต็มรูปแบบตามที่ตกลงกันไว้ — เพิ่มภายหลังได้)
- `อัปเดตล่าสุด` บันทึกเป็นเวลาประเทศไทย (Asia/Bangkok) เสมอ ทั้งตอนเพิ่มและแก้ไข
- **หมายเหตุการย้ายโครงสร้าง**: เดิมมีชีต `Printer` และ `ServerPC` แยกกัน ตอนนี้รวม/แยกใหม่เป็น `PrinterServer` (รวม Printer กับ Server เป็นประเภทเดียว) และ `PC` (แยกออกมาต่างหาก) — ถ้าชีต `Printer`/`ServerPC` เดิมยังว่างอยู่ ให้ลบทิ้งได้เลยแล้วรัน `setupSheets()` เพื่อสร้างชีตใหม่ 2 อันนี้ขึ้นมาแทน แต่ถ้ามีข้อมูลกรอกไว้แล้วในชีตเดิม ให้คัดลอกข้อมูลไปวางในชีตใหม่ตามคอลัมน์ที่ตรงกันด้วยตัวเองก่อนลบชีตเดิม

## ฟีเจอร์ในระบบ

- **แดชบอร์ด**: การ์ดสรุปจำนวนอุปกรณ์แต่ละประเภท (กรองตามสาขาได้) + ตารางอุปกรณ์สำรองพร้อมใช้งานรวมทุกประเภท
- **ค้นหาเบอร์โทร**: ค้นหาเบอร์ภายใน/สายตรง/แผนก/ตำแหน่งแบบ real-time (พิมพ์แล้วกรองทันที ไม่ต้องกดค้นหา)
- **จัดการอุปกรณ์**: สลับดูตามประเภท (IP Phone / EDC / Pinpad / Printer / Server-PC), ค้นหาในรายการ, กดแถวเพื่อแก้ไข, ฟอร์มเพิ่ม/แก้ไขมีช่อง PIN ยืนยันทุกครั้ง, ช่องอาคาร/ชั้น/แผนก/ตำแหน่งย่อยมี autocomplete จากข้อมูลที่เคยกรอกไว้
- **เลือกสาขา**: มุมขวาบนของทุกหน้า มีผลกับแดชบอร์ด, ค้นหาเบอร์, และรายการอุปกรณ์พร้อมกัน

## หมายเหตุการใช้งานต่อ

- ยังไม่ได้ทำระบบ "สถานะอุปกรณ์" แบบเต็ม (เช่น ใช้งานอยู่/ชำรุด/ส่งซ่อม) ตามที่แจ้งว่ายังไม่จำเป็นตอนนี้ — ถ้าต้องการเพิ่มภายหลัง สามารถเพิ่มคอลัมน์ในชีตและเพิ่ม field ใน `ASSET_TYPES`/`SHEET_DEFS` ได้โดยไม่กระทบโครงสร้างเดิม
- รองรับหน้าจอเล็กสุดตั้งแต่ 320px (iPhone 6s) ถึงจอ Desktop/4K, ปุ่มและช่องกรอกออกแบบให้กดง่ายด้วยนิ้ว (touch-friendly)
- ไม่ได้ใช้ Library ภายนอกที่หนัก ใช้แค่ Tailwind (CDN) เพื่อให้โหลดเร็วบนอุปกรณ์สเปกต่ำ
